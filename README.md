# Offside Video Catalog

> **Note:** Offside is a simple, personal side project created purely for fun and personal convenience. It is provided "as-is" without any guarantees or maintenance obligations.

---

## 🌟 Features

- **Thumbnail Preview:** Displays video thumbnails alongside file names for quick visual recognition.
- **Fast Search:** Easily search and filter through local video files by name.
- **Built-in Player:** Click on any video to open and play it immediately.
- **Local Folder Indexing:** Scans and indexes video files from a designated folder.

## 🚀 How to Use

The project currently operates as a Jupyter Notebook interface divided into two cells:

1. **Cell 1 (Update/Index):** Run this cell to scan the folder and update the thumbnail index and video list.
2. **Cell 2 (Launch UI):** Run this cell to open the video gallery interface and start searching/playing videos.

### Executable Build
- A standalone executable (`.exe`) compiled from the Python version is available for quick usage targeting a specific directory.
